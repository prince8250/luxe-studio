# Design Reference

These screenshots show the **feel, structure, and visual language** the developer wants for the public site. They come from a barbershop template ("DS Barbers"). They are a reference for look and layout only.

- Do **not** copy the template's text, logo, photos, or branding. Bestman Luxe Studio uses its own name, logo, copy, and photos.
- Do **not** assume the template's services (haircuts, shaves) apply. The studio's services come from the database.
- `ui-context.md` describes what these images show in words and is the written source of truth. When the words and the pictures disagree, ask the developer.
